# 個人商店（攤位）

玩家用背包裡的東西開自己的店。店的貨存在外掛的資料庫，不是實體箱子，所以漏斗、掉落物、複製都碰不到；店主不用在線，貨款直接進他的帳戶。

## 名詞
- **攤位**：一間店，屬於一位店主，有名稱（最多 24 字，不含顏色碼，全伺服器不重複，大小寫視為相同）。
- **庫存**：店主從背包存入的物品，每種商品一行：完整物品（代碼、損傷值、自訂名稱、說明、附魔等整份 NBT）、數量、每個的價格。完全相同的物品合為同一行；賣完或領完的行消失。
- **告示牌**：攤位的位置。第一行寫 `stall.sign-tag`（預設 `[stall]`），第二行寫攤位名稱（只有一個攤位時可留空）。外掛檢查後改寫牌面：名稱、店主、狀態、「右鍵瀏覽」。告示牌是選用的，攤位也能只用指令開。

## 放告示牌的規則
- 有 tokaLand：只能放在自己擁有或承租（有該領地管理權）的領地內；領地系統一時無法確認時不放。
- 沒有 tokaLand：需要權限 `tokashop.stall.anywhere`。
- 店主不再擁有或承租那塊領地時，攤位休業（買家不能買），庫存保留，店主仍可用 `/shop my` 領回。店主在線時，每次開啟自己的攤位、上線、買家逛店都會重新向 tokaLand 確認；店主不在線時，只比較告示牌下的領地有沒有變，變了就休業，不會自己重開。
- 拆告示牌只有店主或管理員可以，拆掉後攤位保留。

## 買家
- 右鍵告示牌、`/shop visit <攤位>`、或商店主視窗的「攤位」清單進入。
- 商品清單可搜尋、分頁，返回在最前，關閉（紅色）在最後。
- 點商品看代碼、名稱、別名、歸屬，輸入組數與個數（沿用商店的「N 個 = A 組 B 個」寫法），確認視窗列出每個價格、共、消費稅、合計、餘額。
- 付款：先檢查庫存、價格、背包空位，再向買家 `withdrawOnce`（操作 ID `stall-buy:<成交編號>`）。付款成功後再檢查一次（庫存、價格、營業狀態、背包），任何一項不符就全額退款；通過才扣庫存、給物品。
- 貨款 `depositOnce` 給店主（操作 ID `stall-sale:<成交編號>`）。成交編號先記在攤位的「待入帳」裡，入帳成功才移除並計入收入；失敗或重啟會用同一個編號重試（插件啟動、店主上線、開啟 `/shop my` 時），所以不會付兩次。
- 消費稅由買家另付，設定 `stall.tax`（-1 為跟 `tax.window` 一樣），稅金走和商店相同的路徑存入 `tax.account` 或 tokaRegions 的主國庫。店主收到的是完整的標價。
- 不能買自己的攤位。

## 店主
`/shop my`、主視窗的「我的攤位」、或右鍵自己的告示牌：
- 攤位清單：建立。每人上限 `stall.max-per-player`。
- 單一攤位：存入商品（選背包格、數量、每個價格）、商品清單（改價、領回）、開始營業／休業、改名、刪除（需庫存和待入帳都是空的，並要確認）。狀態頁顯示商品數、庫存、至今收入、待入帳、告示牌位置。
- 同一商品再存入會併入原本那行，價格改成這次填的。每種商品最多 1,000,000 個。
- 每個動作都重新確認攤位仍是自己的；表單送來的數字一律解析並限制範圍（價格 1 到 `stall.max-price`）。

## 管理員
`/shop stall list|close <攤位>|open <攤位>|remove <攤位> [force]`（權限 `tokashop.admin`）。close 之後店主不能自己重開，但仍可領回庫存；remove 在還有庫存或待入帳時需要加 `force`。

## 指令與權限
- `/shop my`、`/shop visit <攤位>`、`/shop stall ...`，Tab 會列出攤位名稱（空格以底線顯示，兩種寫法都認得）。說明在 `/shop help`。
- `tokashop.stall`（預設所有人）：開設與管理自己的攤位。
- `tokashop.stall.anywhere`（預設 OP）：沒有 tokaLand 時可在任何地方放告示牌。

## 設定（config.yml）
`stall.max-per-player`（3）、`stall.max-products`（27）、`stall.max-price`（1000000）、`stall.tax`（-1）、`stall.sign-tag`（`[stall]`）、`storage.backend`（SQLITE、JSON、YAML）、`storage.directory`（`stalls`）。

## 資料
用 tokaStorage 的文件儲存，一個攤位一份文件（鍵 `stall-<UUID>`），啟動時全部讀進記憶體，並建好「店主→攤位」「名稱→攤位」「告示牌位置→攤位」三個索引；點告示牌或輸入名稱只查表，不掃描。寫入在一條背景執行緒上依序進行，關閉時等寫完。

## 分租領地
攤位只要求「這塊領地是店主擁有或承租的」，租賃本身是 tokaLand 的事（見 tokaLand 的 `docs/LEASING.md`），店不收租金。

## 沒有做的
向玩家收購（店內資金）、競標、退租時把庫存轉入信箱、跨伺服器。
