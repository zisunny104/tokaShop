# 個人商店與分租領地（設計草案）

目標：車站對面的空間分租給玩家，玩家在自己的攤位開店；店的運作靠預先存入的貨與錢，不靠玩家在線。

## 名詞
- **攤位**：一塊可出租的下級領地（tokaLand 的下級領地，屬於「出租地」），有租金、租期、狀態（空置、出租中、競標中）。
- **承租人**：目前租用攤位的玩家，在攤位內有建造與設定權，攤位外沒有。
- **店內庫存**：玩家先存入的物品，存入後屬於店，不在背包也不在箱子。
- **店內資金**：玩家先存入的錢，用來回收（向玩家收購）物品。

## 玩家個人商店能不能建立？
可以，分兩種：
1. **攤位店**（建議先做）：只能開在出租攤位，用告示牌或視窗賣、收。價格由店主定，但被官方價格夾住（買價不得低於官方回收價，賣價不得高於官方販售價的 N 倍），避免洗價與套利。
2. **自由店**（之後再說）：任何自己的領地都能開，要另付開店費。

## 預存的運作
- 賣給玩家：從店內庫存扣貨、貨款進店主的帳戶（扣交易稅，進主國庫）。庫存沒了就顯示「缺貨」。
- 向玩家收購：從店內資金扣款，物品進店內庫存；資金不足或庫存滿就停收。
- 提領：店主可隨時領回庫存與資金；退租時強制結算，沒領完的轉入店主的信箱。
- 物品只收原版無特殊資料的，與官方商店一致。

## 租賃屬於領地，不屬於商店
- 個人商店本身不收租金；要不要收租，是領地有沒有「租賃機制」的事。
- 領地的租賃可設定租金、週期，並設定**租金收款對象**，預設是領地擁有者（也可改成主國庫或其他帳戶）。
- 餘額不足寬限數日，仍不足則收回，庫存與資金結算給承租人。續租優先於競標。

## 競標（可選，第二階段）
- 攤位空出時開標：起標價＝底租，加價幅度固定，限時（例如 48 小時），出價時凍結款項，被超過時退回。
- 得標者簽一個租期；得標價就是該期租金（付給租金收款對象），下期回到底租或續標。
- 規則簡單、全程自動，不需要管理員介入。

## 需要的元件
| 元件 | 工作 |
|------|------|
| tokaLand | 出租地類型、下級領地、租期與狀態、到期收回 |
| tokaShop | 攤位店資料（庫存、資金、價格）、告示牌與視窗 |
| tokaEconomy | 凍結與扣款（競標、租金），已有 `withdrawOnce` 等 |
| tokaRegions | 主國庫帳戶（已提供 `treasuryAccount()`） |

## 建議階段
1. 官方商店上線（進行中）。
2. 出租地與固定租金（tokaLand）。
3. 攤位店：存入、告示牌買賣、提領、退租結算。
4. 競標。
